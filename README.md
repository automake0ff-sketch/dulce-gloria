# Dulce Gloria Sweets & Coffe — Microapp Premium

Experiencia digital personalizada construida a partir de las **fuentes oficiales** de Dulce Gloria.

## Novedad: Crea tu propia tarta

Configurador interactivo con:
- Vista previa visual en tiempo real (capas CSS)
- Selección de tipo, tamaño, cobertura y decoraciones
- Mensaje personalizado sobre la tarta
- Resumen dinámico + copiar + WhatsApp
- Opciones marcadas como **provisionales / demostración**

## Fuentes utilizadas

| Fuente | Uso |
|--------|-----|
| [Web oficial](https://dulcegloria.com/) | Historia, filosofía, contacto, horarios |

| Instagram @dulcegloriasweetsandcoffe | Personalidad visual |
